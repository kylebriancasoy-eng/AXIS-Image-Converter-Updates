# AXIS Image Converter Updates

Public Windows installers and update metadata for **Atom Extensible Interface Systems (AXIS)** Image Converter.

Download setup from Releases. The application is currently Alpha and its setup is unsigned. Setup can install a new copy or update/repair an existing app while preserving external settings, history, Terms acceptance and converted files.

The app checks `latest.axs` over HTTPS without a GitHub account. It validates the version, installer size and SHA-256 before opening setup after your confirmation. Automatic checks can be turned off in the app's Updates panel.

This repository contains release metadata, checksums, notes and installers. The application source repository remains private. Copyright 2026 Atom Extensible Interface Systems (AXIS). All rights reserved.
